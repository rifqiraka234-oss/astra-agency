# Notes 17B: type on premium dessert sites, and local rival teardown (research only, 28 Oct 2026). Tooling: https://playwright.dev/ driving installed Chrome 156 headless.

## 0. Method and honest caveats - https://playwright.dev/

- Each site was rendered in headless Chrome 156 (channel chrome, playwright-core 1.64) at 1440x900 with a Windows Chrome 156 user agent; phone shots use 390x844, isMobile, hasTouch and an Android Chrome UA. https://playwright.dev/docs/api/class-browsertype
- Runtime fonts: document.fonts entries with status loaded are listed; computed font-family, weight, letter-spacing and text-transform come from getComputedStyle on the first visible h1, h2, body, nav link, button and price. https://developer.mozilla.org/en-US/docs/Web/API/Document/fonts
- The font actually painted per element was read with Chrome DevTools Protocol CSS.getPlatformFontsForNode, because a declared name can lie (Pierre Hermé declares "Futura" and paints Jost). https://chromedevtools.github.io/devtools-protocol/tot/CSS/#method-getPlatformFontsForNode
- Foundry and licence evidence comes from the name table of every downloaded font file (manufacturer, designer, licence URL, copyright), read by a small woff/woff2/ttf parser, then confirmed against foundry, Adobe Fonts, Google Fonts or GitHub pages (links on each line). https://learn.microsoft.com/en-us/typography/opentype/spec/name
- This machine geolocates to the Netherlands, so some sites served an NL/EU storefront (Amorino /nl, Läderach /eu-en, Ladurée country picker, Fortnum's country picker). Where a country or newsletter modal covered the hero it was hidden with CSS for the screenshot. https://laduree.com/en-uk/ https://www.amorino.com/nl
- Cookie banners were never accepted. Pierre Hermé's Didomi wall was dismissed with its own "Continuer sans accepter" (continue without accepting) control; Amorino's with "Refuser"; all other banners were hidden with CSS. https://www.pierreherme.com/ https://www.amorino.com/nl
- Pierre Hermé's hero is a full-bleed video that headless Chrome paints white, so white header type is invisible; the shipped screenshot replaces the video with a flat brown field (raw shot kept alongside). https://www.pierreherme.com/
- Nothing was submitted, no form filled, no account created; bot walls were not attempted or bypassed. https://playwright.dev/
- Dropped sites: Venchi (https://www.venchi.com/ -> https://eu.venchi.com/ redirects to google.com client-side in headless Chrome), Sugarfina (https://www.sugarfina.com/ 403 DataDome slider challenge). Kaspa's (https://www.kaspas.co.uk/) served a reCAPTCHA image challenge and is covered from public listings only. https://eu.venchi.com/ https://www.sugarfina.com/
- Dominique Ansel: the shop.dominiqueansel.com host in the brief does not resolve, https://www.dominiqueansel.com/ was used instead. https://www.dominiqueansel.com/
- Charbonnel et Walker loaded but declares Playfair Display without any @font-face, so nothing usable rendered (Times New Roman fallback); it is shown but excluded from pattern counts. https://charbonnel.co.uk/
- Raw JSON per site (document.fonts, file metadata, CDP fonts, computed styles): C:\Users\RifqiRakamulya\Documents\Astra\charlie\_research\type\data\ and C:\Users\RifqiRakamulya\Documents\Astra\charlie\_research\rivals\data\ - scripts in C:\Users\RifqiRakamulya\Documents\Astra\charlie\_tools\research-type-rivals\ https://github.com/microsoft/playwright.
- Never confused with the Cheadle "Charlie's Desserts" on Deliveroo; Charlie's here means the Brighouse and Huddersfield parlour from the brief, and no Charlie's site was touched. https://deliveroo.co.uk/
