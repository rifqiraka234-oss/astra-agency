## Notable issues / infrastructure note

lemlist's MCP tools do not expose a way to fetch a single company record
(`cpn_xxx`) with its richer fields (description, foundedOn, industry,
location, domain) — `search_companies` only returns id/name/domain/sync
status, and there is no `GET /companies/{id}` endpoint available through
`call_api`. Company context for this run came instead from each contact's
own lemlist enriched fields (`summary`/`tagline`, which often name the
company and role) plus independent web research, not from a lemlist company
record lookup. This worked for all 3 contacts here but is a real gap for
contacts whose tagline/summary doesn't name their company — worth flagging
to Raka; may need a lighter fallback (e.g. web search on name + location)
for those cases in future runs.
